## WE Invoice 0.1.4

A fix of the import from iDoklad. An app that is already installed updates itself.

### Fixed

- **Import from iDoklad:** the list of issued invoices exported from the Slovak iDoklad is read in full. Its columns ("Názov/Meno", "Vystavenie", "Dodané", "Dátum platby") were not recognised, so every invoice was skipped. Dates written month first (10/22/2026), as iDoklad exports them for an account in English, are read correctly.

### Installing

See [Installing](https://github.com/JaffarSk24/WE-Invoice#installing) in the README. The installers are not signed with a paid certificate yet: macOS needs one command after the first install, and Windows shows a SmartScreen warning.
