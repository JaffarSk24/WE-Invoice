## WE Invoice 0.1.2

A fix for the desktop app. An app that is already installed updates itself.

### Fixed

- **Connecting an e-invoicing provider in the desktop app:** the client id and secret (or API key) of the provider were refused with "Invalid key value", whatever was entered, so the connection could not be saved. The same stopped the beta invitation and the SuperFaktúra API key from being remembered. The web app was not affected.

### Installing

See [Installing](https://github.com/JaffarSk24/WE-Invoice#installing) in the README. The installers are not signed with a paid certificate yet: macOS needs one command after the first install, and Windows shows a SmartScreen warning.
